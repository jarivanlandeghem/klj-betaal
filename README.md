# KLJ betaalpagina

Statische pagina achter de betaallinks van de KLJ Kasboek-app. Alle gegevens (IBAN, begunstigde,
bedrag, mededeling) staan in het stuk na `#` van de link en worden nooit naar een server gestuurd.
De pagina toont ze met kopieerknoppen en een SEPA-betaal-QR (EPC069-12) voor de bankapp.
